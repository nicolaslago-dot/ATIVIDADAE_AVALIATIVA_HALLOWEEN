# Halloweenflix — atividade em equipe de HTML e CSS

## Sobre a atividade

Nesta atividade, a turma vai trabalhar em equipe para revisar e melhorar o
Halloweenflix, um site fictício de filmes de terror. Cada equipe ficará
responsável por uma parte do projeto, mas todas devem colaborar para que as
páginas tenham o mesmo visual e funcionem em conjunto.

Além de desenvolver o conteúdo e os estilos, procurem os erros simples
colocados de propósito nos arquivos HTML. Corrijam-nos e confiram se os links,
as imagens e as páginas continuam funcionando.

O projeto é feito com HTML e CSS. Não é necessário instalar programas ou criar
um sistema para salvar dados: o formulário de cadastro é apenas demonstrativo
e o aluguel não é real.

## Passos para realizar o trabalho

1. Abram `index.html` no navegador e naveguem pelas páginas para conhecer o
   projeto.
2. No editor de código, abram os arquivos da equipe indicados na tabela.
3. Leiam o HTML e procurem erros simples, como nomes de arquivos incorretos,
   links que não levam à página certa ou elementos escritos de forma errada.
4. Corrijam os erros encontrados e completem ou melhorem a parte da página
   atribuída à equipe.
5. Escrevam ou ajustem o CSS correspondente. Usem os estilos de
   `css/global.css` como base comum para todas as páginas.
6. Testem no navegador em telas grandes e pequenas. Cliquem nos links e
   verifiquem se as imagens aparecem.
7. Revisem o resultado com as outras equipes e preparem uma breve apresentação
   com a participação dos três integrantes.

## O que cada equipe deve observar

- **Equipe 1:** o logotipo e os links devem funcionar; o menu deve se adaptar a
  telas menores e permanecer legível.
- **Equipe 2:** a página deve ter conteúdo temático, imagens disponíveis e
  recomendações com links válidos.
- **Equipe 3:** cada filme deve ter imagem, título, gênero, classificação,
  sinopse e link para os detalhes. Os links das categorias devem levar ao card
  correspondente.
- **Equipe 4:** os detalhes devem corresponder aos filmes do catálogo. O
  formulário deve ter rótulos associados aos campos e deixar claro que não
  salva informações.
- **Equipe 5:** a página inicial deve apresentar o projeto com clareza e dar
  acesso ao catálogo, às categorias e ao especial de Halloween.

## Arquivos do projeto

- `index.html`: página inicial.
- `filmes.html`: catálogo de filmes.
- `categorias.html`: categorias de terror.
- `halloween.html`: especial de Halloween.
- `detalhes-filme.html`: informações e sinopses dos filmes.
- `cadastro.html`: formulário demonstrativo.
- `favoritos.html`: mural complementar de mídias favoritas.
- `css/`: estilos comuns e estilos das páginas.
- `imagens/`: logotipo, banner e cartazes dos filmes.

## Conceitos de HTML usados

- `<h1>`, `<h2>` e `<h3>` organizam os títulos.
- `<p>` cria parágrafos; `<a>` cria links; `<img>` exibe imagens.
- `<header>`, `<nav>`, `<main>`, `<section>` e `<footer>` organizam as áreas da
  página.
- `<div>` e `<article>` agrupam conteúdo, como os cards dos filmes.
- `class` permite aplicar um estilo a vários elementos; `id` identifica uma
  parte específica da página.
- `<label>` identifica um campo do formulário. O valor de `for` deve ser igual
  ao `id` do campo relacionado.
- `<!-- comentário -->` aparece no código como orientação, mas não é exibido
  como conteúdo da página.

## Entrega

Ao final, entreguem as páginas HTML revisadas, os estilos CSS da equipe, as
imagens organizadas e uma apresentação breve do trabalho. Antes de concluir,
confirmem que não há links ou imagens quebrados e que as páginas podem ser
usadas em computador e celular.
